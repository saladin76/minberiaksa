- نقطة البداية: `35180bc75900e904f536450d5c6c4cb4caaa2a50` (`main` وقت التقسيم). لا تبنِ عملك على PR #143؛ فهو مستقل ومفتوح حتى الآن.
- لا تعمل مباشرة على `main` أو `integration/translation-seo-20261107`. أنشئ Draft PR إلى **فرع integration** للتسليم بعد رفع تعديلاتك إلى فرعك.
- استخدم ترجمة عربية أساسية، 19 لغة مدعومة حيث تنطبق، والكتابة RTL/LTR الصحيحة. لا تُصدر ترجمة آلية بغير مراجعة؛ احفظ بنية النص والروابط والعناصر المحمية.
- لا تكتب على قاعدة بيانات الإنتاج؛ استخدم fixtures/mocks والقراءة فقط. لا تغيّر الدفع أو تبرعات المتبرعين أو أنظمة الرسائل أو مسارات URLs الحالية من دون 301 مع اختبار.
- أي تغيير في ملف مشترك مع فرع آخر يُوقف حتى تتواصل مع محادثة الدمج وتوثق السبب؛ لا توسع النطاق تلقائيًا.
- اختبر `npm run test:content-editors` و`npm run typecheck:content-editor-service` و`npm run typecheck:baseline` و`npm run lint:ci`، مع اختبارات دقيقة لكل ميزة جديدة. إذا تطلب الاختبار توليد Prisma، استخدم بيئة معزولة بلا بيانات إنتاج.
- التسليم: رابط Draft PR + SHA + ملفات معدلة + اختبارات ونتائجها + صور/لقطات قبل/بعد + مخاطر + قائمة أمور لم تُنجز. لا تزعم نجاح نشر أو استعادة غير مؤكدة.

**الهدف:** إصلاح ترجمة إنشاء/تعديل المقالات والبانرات والشرائح بجميع اللغات، مع الاحتفاظ بالمحتوى والصور والفيديو والتنسيق، ومراجعة وحفظ الكل مرة واحدة.

**الملفات المملوكة حصريًا:** `app/(dashboard)/dashboard/blog/**`، `app/(dashboard)/dashboard/slides/**`، `app/(dashboard)/dashboard/_components/ProjectEditorSectionsEnhancer.tsx` **فقط إذا ثبت صلته**، `app/api/posts/[postId]/translations/route.ts` إذا احتاج GET فقط دون تغيير صلاحيات، اختبارات جديدة بأسماء `tests/content-editor/translation-blog-*.test.ts`.

**أعمال محددة:**
1. العربية أساس، ترجمة بقية اللغات وحفظ جماعي ناجح ومراجعته على create/edit والـslug/SEO للمدونة دون كسر أي رابط.
2. إصلاح حالات فقدان المحتوى المنسق في محرر المقالات عند ترجمة/تنقيح النص وتغيير اللغة، وتدقيق الاشعارات وفشل بعض اللغات.
3. ترجمة السلايدر والبانرات والحقول النصية والصور لكل لغة وفق بنية البيانات الحالية؛ لا تكرر الصور تلقائيًا ولا تُبدل وسائط المستخدم.
4. اختبارات إنشاء/تعديل/إعادة تحميل، حفظ جماعي، وحالات نص منسق متعدد الفقرات.

**ممنوع:** تحرير `components/dashboard/content-editor/**` (المحادثة 2)، `lib/content-localization/**` (المحادثة 1)، أو إعدادات sitemap/SEO العامة.

**ملاحظة:** أي خدمة محتوى عامة مشتركة تُطلب من محادثة الدمج أولًا.
