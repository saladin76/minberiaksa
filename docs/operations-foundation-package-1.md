# Operations Foundation - Package 1

## Goal

Create a dedicated Operations area without changing Marketing.

## Included

- /dashboard/operations
- Operations vision
- Responsibility boundaries
- Future package roadmap

## Not Included

- Database models
- APIs
- Calendar logic
- Content workflow
- AI automation
- Messaging

## Why

Small package size keeps GitHub PRs and Vercel deployments safe, reviewable, and easy to merge.
